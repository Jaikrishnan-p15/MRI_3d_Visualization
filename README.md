# MRI_3d_Visualization
End-to-end 3D Brain MRI Tissue Segmentation &amp; Interactive Isosurface Reconstruction pipeline using BraTS 2020 NIfTI volumes, Multi-Otsu/K-Means clustering, 15 quantitative validation metrics, and Marching Cubes WebGL visualization. Built for EC1066 (Biomedical Signal &amp; Image Processing) at NIT Puducherry.
